# Hi, I'm Prem 👋

**I build my own corner of the internet** — self-hosted apps that replace the

## 🚀 Featured projects

### 🎵 [music-server](https://github.com/goldhap/music-server) — *bali-music*
My own private Spotify: a self-hosted music streaming platform with
admin-created accounts (no public sign-up), a shared library with per-user
playlists & favorites, gapless playback with crossfade, loudness
normalization, synced lyrics, radio, YouTube import and offline downloads.
Engineered until lock-screen playback on iPhone behaved like a native app.

`Next.js` · `FastAPI` · `PostgreSQL` · `Docker` · Live: music.moklav.tokyo

### 📻 [nepali-radio-player](https://github.com/goldhap/nepali-radio-player)
Every Nepali radio station in one place — 589 stations, favorites, sleep
timer, EQ and a hardened streaming proxy.

`JavaScript` · `PWA` · Live: radio.moklav.tokyo
